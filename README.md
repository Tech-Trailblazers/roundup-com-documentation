## 📘 What Are SDS and MSDS?

- **SDS (Safety Data Sheet)**: A standardized document that communicates hazards, handling, storage, and emergency procedures for chemical products.
- **MSDS (Material Safety Data Sheet)**: An earlier format of the SDS (now largely replaced), but still valuable for reference and historical data.

These documents are essential for:

- 🧑‍🔬 Chemical safety and compliance training
- 🧠 Teaching machines to understand regulatory documentation
- 📊 Structuring data for NLP and information extraction
